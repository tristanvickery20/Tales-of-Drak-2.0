# Drak Hotbar Standalone Prototype

This folder is a separate Godot project for building the Tales of Drak combat hotbar before porting it into the main game.

Open `standalone/hotbar_prototype` as its own Godot project.

Step 1 goal:
- standalone project opens
- hotbar scene is the main scene
- UI sits centered at the bottom of the screen
- no main game files are touched
