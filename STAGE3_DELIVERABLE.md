# Stage 3 Deliverable — Race/Species + Class Foundation

## Stage 3 Goal

Create the first tiny race/species and class foundation for Tales of Drak without breaking the playable iPhone test loop.

Stage 3 should not build the whole character creator. It should only establish the data shell that later systems will use.

## Required Playable Loop Preservation

The project must still:

- Open through GitHub Pages/Safari on iPhone.
- Start from the main menu.
- Load the test world.
- Move with the current mobile movement controls.
- Jump.
- Interact.
- Pick up existing test resources.
- Enter and exit the cave.
- Open and close the mobile Sheet.
- Keep Stage 2 rules foundation available.

## Approved Race/Species Scope

Only these race/species IDs are allowed in Stage 3:

- Elf
- Variant Human
- Dwarf
- Orc

Do not add other playable races/species unless explicitly requested.

## Approved Class Scope

Only these class IDs are allowed in Stage 3:

- Fighter
- Wizard
- Cleric
- Warlock
- Rogue
- Barbarian
- Ranger

Do not add Bard, Monk, Paladin, Sorcerer, Druid, Artificer, or other classes unless explicitly requested.

## Stage 3A Target

Add a tiny character identity shell:

- Character name placeholder.
- Selected race/species placeholder.
- Selected class placeholder.
- Current level placeholder.
- Sheet display for character identity.
- One harmless Sheet preview button.

No traits, class features, combat abilities, spells, equipment, or stat changes yet.

## Stage 3 Later Passes

Recommended sequence:

- 3A: Character identity shell.
- 3B: Race/species registry with approved race/species IDs only.
- 3C: Class registry with approved class IDs only.
- 3D: Fighter level 1 shell only.
- 3E: Wizard/Cleric/Warlock spellcasting identity shell only.
- 3F: Rogue/Barbarian/Ranger identity shell only.
- 3G: Stage 3 audit and cleanup.

## Explicitly Not In Stage 3 Yet

- No full character creator UI.
- No face/body sliders.
- No new 3D character models.
- No combat hotbar.
- No enemy combat.
- No real spellcasting.
- No inventory/equipment implementation.
- No crafting.
- No taming.
- No quests.
- No dialogue.
- No Skelerealms integration yet.

## Exit Criteria

Stage 3 is successful when the Sheet can show a selected race/species and class foundation from the approved lists while the iPhone playable loop still works.
