# Stage 3 Closeout Checklist

Stage 3 is the first tiny race/species and class foundation.

## Confirmed Direction

- Keep Tales of Drak playable on iPhone through GitHub Pages/Safari.
- Keep the current movement, interaction, pickup, and cave transition loop working.
- Keep Stage 2 rules foundation available.
- Keep character/race/class data under `res://drak/character/`.
- Keep all race/species and class work modular and data-first.
